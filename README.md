# PaperNest — Diary Product Website

A responsive diary and stationery storefront built with **HTML, CSS and JavaScript**.

## Features
- Responsive landing page and product grid
- Product categories: Journals, Planners and Classic
- Add-to-cart interaction and cart item count
- Sample product catalogue with prices in INR
- No framework or installation required

## Run locally
1. Download and extract this project.
2. Open the `diary-store-website` folder.
3. Double-click `index.html` to open it in your browser.

You can also open the folder in Visual Studio Code and use the Live Server extension.

## Customize
- Edit product names, prices, categories and colours in `script.js`.
- Change layout and colours in `style.css`.
- Update the page content in `index.html`.

## Note
This is a front-end demo. The cart is temporary and does not process payments or save orders. A real store needs a backend, database and secure payment integration.
